# 病房每日假資料（mock_data）

> **全部內容皆為虛構**，不含任何真實病患、人員或院內紀錄。人員一律以代碼表示（護理師 `N1xx`、醫師 `D2xx`／`D3xx`、營養師 `R3xx`）。

用途：模擬院方每天交付的病房資料包，供開發與驗證稽核規則 R01–R07。格式依 [院方每日資料交換格式規格](../docs/hospital-data-spec.md)，可用 [patient-daily.schema.json](../docs/hospital-data-spec/patient-daily.schema.json)、[manifest.schema.json](../docs/hospital-data-spec/manifest.schema.json) 驗證。

## 目錄

```
mock_data/
├── 20260901/            # 業務日期（院方 9/2 01:00 產出）
│   ├── manifest.json    # 當天資料包清單
│   ├── A病患.json       # 一位病患一天一個檔
│   └── B病患.json
├── …
└── 20260930/            # 最後一個完整業務日
```

- 病房：W51 內科病房；期間 2026-09-01 ～ 2026-09-30，共 30 個資料包、65 個病患檔
- **增量**：每個檔只放當天新增或修改的紀錄；入院護理評估只出現在入院當天
- 會診在開立、簽收、回覆任一狀態改變的那天出現；管路為當天現況清單
- 臨時醫囑與高警訊用藥才放在 `medication_orders`（D 病患 9/19–9/22 另放常規抗生素，作為邊界測試）
