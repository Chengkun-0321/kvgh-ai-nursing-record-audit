# ADR 0008：頂部導覽列與暖亞麻極簡配色（液態玻璃只當點綴）

- 狀態：提議
- 日期：2026-09-28

## 背景

- 使用者希望外框改成「極簡風＋液態玻璃點綴」：導覽列在上，設定頁左側有分頁導覽。
- 底色不是白色，而是一層淺色底；內容放在近白卡片上，高彩度色只占極小面積。首頁病房模型的顏色不變。
- 初版依使用者建議採青綠配色（背景 #F0FDFA、文字 #134E4A、主色 #0891B2），實際套用後，冷薄荷底色與病房的橡木床頭、米白燈光、奶茶色地板幾乎是互補色，兩者又都是大面積低彩度，病房看起來像貼在畫面上的另一套素材。
- 使用者比較三組方案（暖亞麻＋深青、鼠尾草＋橡木、石墨霧灰）後選定「暖亞麻＋深青」。
- ADR 0005 的滿高玻璃側欄會占掉病房左側寬度，設定頁與病患頁的大片玻璃面板也和「極簡」方向不合。

## 決策

1. **桌機（lg 以上）改為頂部導覽**（`AppNavBar`），取代側欄：
   - 三座浮動玻璃膠囊：左為系統標誌、中為主要導覽、右為時間／待處理數／使用者。
   - 導覽置中於視窗；外層不接收指標事件，膠囊之間仍可拖曳病房。
   - 目前頁以白色實色膠囊標示，換頁時以 `SPRING_DEFAULT` 滑動（layoutId）。
   - 窄桌機收合：標誌名稱與使用者姓名 xl 以上才顯示，時間 2xl 以上才顯示。
2. **手機維持頂列＋底部分頁列**（iOS 慣例，拇指好按），只套用新配色。
3. **層次**：
   - 底色：暖亞麻 `page-backdrop`，全站共用；首頁病房外也透出這層，不再使用獨立的舞台地坪。
   - 內容：白色實色卡片（`surface`＋`shadow-card`）；卡片內的清單改為 `canvas` 淺色區塊。
   - 液態玻璃只用於浮動外框：頂部導覽、手機頂列與分頁列、病房上的標題／狀態列／縮放控制／詳情卡、工作表。
4. **設定頁左側分頁導覽**（`SettingsNav`）：
   - 桌機為 sticky 直欄，手機為橫向膠囊列。
   - 目前只有「LLM 模型」可用。「稽核規則」「使用者與權限」「批次排程」以停用狀態保留位置，標示「即將推出」。
5. **配色與對比**（大面積底色跟著場景走，冷色只留給小面積互動元素）：
   - 底色 `backdrop` #ECE7E0、`canvas` #F6F3EE：取自病房燈光與窗框的米白再降低彩度，病房像延伸出去的同一個空間；陰影也改為暖色調。
   - `ink` #1F2A2C（帶一點青的深炭灰）：白底 14.7:1，玻璃下墊純黑 8.3:1。
   - `ink-secondary` #454D4E：玻璃下墊純黑 4.9:1、白底 8.7:1。
   - 主色 `accent` #0E7490（深青）：白字 5.4:1，可直接當實心按鈕底與 focus 外框（病房暖色地板上 3.4:1），不再需要另一個加深色 token。淺青底上的文字用 `accent-strong` #155E75。
   - 強調色 #16A34A（`positive`）只用於正向狀態（使用中、成功）的圖示與圓點；文字用 `positive-strong` #15803D（白底 5.0:1）。
   - `scene-*`（Blender 材質色）不變。只刪除 `scene-apron`／`-apron-light`：它們只供 CSS 舞台底色使用，Blender 不讀取，不需重建 GLB。

## 影響

- **好處**：
  - 病房可用整個視窗寬度，最小倍率變大。
  - 底色與病房同一色溫，病房外緣不再與底色互相衝突。
  - 各頁的層次一致（底色 → 白卡 → 玻璃外框），視覺更安靜。
- **代價**：
  - 深青在暖底上較沉穩，互動元素的辨識度靠冷暖對比而非高彩度；進度條、選取指示不像亮青那麼跳。
- **後續**：
  - 首次進入首頁時，3D 場景初始化會佔用主執行緒，導覽選取底色的滑動可能停頓。
  - 若正式版仍明顯，再評估把場景初始化再往後延。
