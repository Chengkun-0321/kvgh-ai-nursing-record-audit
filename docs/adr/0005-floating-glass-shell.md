# ADR 0005：桌機工作區外框改為全浮動液態玻璃

- 狀態：外框部分由 0008 取代（側欄與右上膠囊改為頂部導覽；玻璃材質與病房適配留白沿用）
- 日期：2026-09-27

## 背景

ADR 0004 讓病房場景鋪滿視窗，外框疊在場景上，但畫面仍與外框有明顯斷層：

- 病房以最小倍率剛好塞滿安全區，深色牆緣正貼側欄右側與頂列下緣，像一張圖貼在白框裡。
- 頂列是貼齊視窗的整條玻璃帶，側欄卻是浮動卡片，兩種隱喻混用。
- 玻璃為白 0.89，下方又只有平淡地坪，看起來像實心白板，不像疊在場景上的材質。

## 決策

參考 macOS 26／27（Tahoe）的做法，lg 以上：

1. **移除整條頂列**，場景直達視窗上緣。
   - 系統標誌移到滿高浮動側欄的最上方。
   - 時間、待處理數、使用者改為右上角玻璃膠囊（`AppStatusCapsule`）。
2. **統一間距**：側欄、病房標題、使用者膠囊對齊同一條上緣（1rem），所有浮動層與視窗、彼此之間的間距都是 1rem。
   - 詳情卡由 `--spacing-toolbar` 以下開始，不遮住膠囊。
3. **適配留白**：`.ward-safe` 的 padding 定義為病房適配留白（手機 0.75rem、lg 2rem）。
   - 縮放下限、初始視野與平移夾限都以「安全區扣掉 padding」為準（`measureMapArea`）。
   - 病房四周因此留有地坪；放大後病房仍可滑到外框的玻璃下方。
4. **玻璃更通透**：`--color-glass` 由 0.89 降到 0.76，並強化邊緣高光。
   - 為維持「玻璃下墊純黑 ≥ 4.5:1」，`ink-secondary` 由 `#58585d` 加深為 `#48484d`（約 5.1:1）。

手機（< lg）維持頂列與底部分頁列，只套用新的材質。

## 影響

- 好處：功能層成為同一片場景上的浮動玻璃島，場景與外框不再像兩個世界。
- 代價：
  - 最小倍率比原本略小（扣掉 2rem 留白）。
  - 非滿版頁面（病患頁）需由 `main` 的 `lg:pt-toolbar` 讓出頂部空間。
- 後續：手機頂列與分頁列是否也改為浮動膠囊，待使用者回饋後再議。
