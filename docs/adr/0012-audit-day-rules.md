# ADR 0012：稽核日已結束、R06 逐筆追蹤、一次性規則完成後不重跑

- 狀態：採用（決策 3 由 [ADR 0013](0013-admission-rule-rerun.md) 取代）
- 日期：2026-11-16

## 背景

- 本決策修正 [ADR 0011](0011-audit-module.md) 的日期、R06 追蹤與一次性規則行為。
- 稽核日是結果寫入及查詢的日期。R06 使用畫面所選日期。
- 追蹤期限自會診日起算，至會診日加 `AUDIT_CONSULT_FOLLOWUP_DAYS` 日止，兩端均含。
- 追蹤範圍是稽核日減上述天數至稽核日，兩端均含。

## 問題

- 未結束的稽核日仍可能新增紀錄。
- 先前只在期限到期日記錄結果，會診當天看不到當天會診，也看不到同日其他尚未到期的會診。事後回看會診當天仍可能顯示寬限期中。
- 一次性規則重跑會增加結果列與模型費用。院方未提供入院評估修改時間。

## 決策

### 1. 稽核日必須已結束

- 所選日期須早於 Asia/Taipei 的今天。未結束時，可稽核性為 `day_not_ended`，執行回 409 且不寫入。
- 一次性規則也以所選日期判斷是否已結束。
- 未指定日期時，預設已結束的最新資料日；若沒有，使用最新資料日。

### 2. R06 截至稽核日逐筆追蹤

- 專案負責人於 2026-11-16 決定：每個已結束的資料日可稽核追蹤範圍內的會診，結果記在所選稽核日。輸入不含稽核日之後的資料。
- 範圍內有會診即為可稽核，包含尚在期限內的會診；沒有會診時為 `not_applicable`。
- LLM 逐筆比對會診與指定類別護理紀錄，只檢查是否有對應書寫，不比對建議內容。
- 「紀錄完整」表示截至稽核日沒有期限已到而未見對應紀錄的會診。寬限期中不是缺漏，該筆為 `PASS`。
- 整體依序為 `WARNING`、`NEEDS_REVIEW`、`PASS`。卡片顯示整體判定；逐筆訊息在細節中呈現。
- 詳細輸入、狀態、證據與程式核對見 [R06 規則](../conventions/audit-rules.md#r06-會診資訊--護理紀錄事件)。
- 逐筆寬限期發現的判定標籤為「寬限期中」。已見紀錄的發現預設標籤為「紀錄完整」，prompt 要求訊息顯示「已見對應的護理紀錄」；程式未核對訊息是否含此字句。
- 顯示限制：專屬標籤以項目名稱對照。同日同科的不同會診若狀態不同，寬限期標籤可能套到另一筆 `PASS` 發現。

**已驗證（2026-11-16 以實際資料 W63-001 執行，prompt v3，並在病患頁確認顯示）**：追蹤天數 1。

| 輸入 | 步驟 | 輸出 |
|---|---|---|
| 11/04 胸腔內科會診 | 稽核 11/04 | 整體 `PASS`；該筆寬限期中，期限至 11/05 |
| 11/04 胸腔內科會診、11/05 腸胃科會診與護理紀錄 | 稽核 11/05 | 整體 `PASS`；前者已見 11/05 對應護理紀錄；後者寬限期中，期限至 11/06 |

**未驗證**：期限已到且未見對應紀錄的實際資料 `WARNING` 案例。

### 3. 一次性規則完成後不可再執行

> **註（2026-11-25）**：本決策由 [ADR 0013](0013-admission-rule-rerun.md) 取代：入院規則（原稱一次性規則）完成後可單項重新稽核，一鍵稽核不納入。

- R01、R03 最新結果為 `COMPLETED` 時不可再執行，回 409 且不寫入。
- 例外：`NEEDS_REVIEW` 且 `status_reason` 有值的驗證失敗結果仍可重跑。
- 病患頁的 `can_run` 與 `include_in_run_all` 在完成後為 false。

### 4. 對 ADR 0011 的修正

- 修正決策 3 的一次性規則重跑與 R06 事件範圍。
- 修正決策 4 的一次性規則重跑，及決策 7、8 的可執行性與預設日期。

## 影響

- 只有寬限期中會診且 R06 已完成 `PASS` 時，病床總覽的 R06 結果視為「紀錄完整」。床位整體仍取各規則最嚴重的結果。
- 每個稽核日保留當時的結果；目前沒有排程，後續日期須手動稽核。
- 舊 R06 結果查詢未依 prompt 版本過濾；重新稽核後才會由該日較新的結果取代。
- 入院評估修改後沒有重跑入口。病床總覽仍把已完成的一次性規則計入可稽核規則數。
- 未結束日期的病床總覽若無可稽核項目，進度文字為「今日無可稽核項目」。沒有已結束資料日的預設日期也可能未結束。
- **推論**：只有目前提供的資料日能供病患頁選擇；缺少後續資料日會限制到期後的稽核。
