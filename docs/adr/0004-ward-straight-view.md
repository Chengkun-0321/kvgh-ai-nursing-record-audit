# ADR 0004：病房地圖預設改為正視角，保留斜視角切換，場景滿版

- 狀態：提議
- 日期：2026-09-27

## 背景

ADR 0003 的病房場景以斜視角呈現（yaw 13.7°、pitch 36.5°）。實際使用後發現兩個問題：

- 病房投影成平行四邊形，四周留下大塊三角形空白。
- 外框是白底頂列加浮動側欄卡，畫面更顯得空。

使用者提供新的正視角病床拼版圖（3 張 2×4，對應三個年齡層），並以概念圖為目標：場景鋪滿整個視窗，功能層都是疊在場景上的玻璃。原本的斜視角先保留，不刪除。

## 決策

1. **兩個視角，各一套資產**
   - 設定檔拆成 `frontend/src/lib/wardKit.straight.json`（預設）與 `wardKit.tilted.json`（原 `wardKit.json`；角度與尺寸不變，只新增 `id`、`style`、`modelDir`、`spriteDir`、`bedProxy`）。
   - 每個設定檔以 `modelDir`、`spriteDir` 指向自己的 GLB 與去背圖：
     - 正視：`public/models/ward-straight/`、`public/images/beds-straight/`
     - 斜視：沿用 `public/models/ward/`、`public/images/beds/`
   - 前端的投影（`createWardView(kit)`）、版面（`buildWardLayout(beds, kit)`）與素材選擇都改為依設定檔計算。
2. **切換方式**：地圖控制列新增「正視／斜視」切換鈕（`aria-pressed`）。
   - 切換時不重新掛載地圖，焦點留在切換鈕上。
   - 3D 場景只換模組網址，視野重設為完整顯示。
3. **Blender 管線**：所有腳本以 `--view straight|tilted` 選擇設定檔，預設 straight。
   - 輸出目錄、算圖快取、校準檔、預覽 `.blend` 都依視角分開。
   - 模組依設定檔的 `style` 分支：`leftLook` 為原斜視配置；`symmetric` 左右都是矮牆、隔簾收攏在床頭端、前緣為低矮剖面牆、不建樓板。
4. **正視角校準**：yaw 0 時原本的斜率公式無解，且生成的去背圖並非嚴格的正交投影。
   - 俯角（pitch 60°）改由校準檔指定，依床尾板正面與腳輪的比例目測。
   - 每公尺像素與床心錨點仍以前輪位置做最小平方擬合。
   - 生成圖的床身較短（約 0.96 × 1.1 m），床下陰影代理物（`bedProxy`）依此設定。
5. **滿版舞台與安全區**
   - `.ward-stage` 固定鋪滿視窗，頂列、側欄與手機分頁列疊在場景上。
   - `.ward-safe` 以 CSS 扣掉這些外框；病房的縮放下限、初始視野、平移夾限，以及標題、狀態列、詳情卡、縮放控制的定位都以安全區為準。
   - 病房外（含外框後方）以靜態暖灰地坪（`--color-scene-apron`）填滿，不再露出白底。

## 影響

- **好處**
  - 預設畫面接近概念圖，四周不再有大塊空白。在 1650×870 視窗下，10 床病房幾乎剛好填滿安全區。
  - 斜視角保留可用；兩套資產互不影響，可各自重建。
  - 正視角模組 12 個約 236 KB，比斜視角（364 KB）小。
- **代價**
  - 兩套 GLB 與去背圖都要維護。修改共用道具後，兩個視角都要重建，並各自遞增 `assetVersion`。
  - 正視角的俯角為目測值；若更換去背圖，需重新標記點位並比對疊圖。
  - 地坪是純色與靜態柔光，平移時不會移動；若要加紋理，需改成 3D 場景內的平面。
- **後續**
  - 概念圖中的護理站、走廊門、洗手間等周邊環境，本次依使用者決定未做；之後可新增為正視角的額外模組。
