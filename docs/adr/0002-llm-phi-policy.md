# ADR 0002：病患資料外送 LLM 政策（暫行）

- 狀態：採用（暫行）
- 日期：2026-09-26

## 背景

使用者可在網頁設定任意 LiteLLM 支援的模型，包含雲端 API。目前系統只處理院方提供的假資料，尚未接觸真實病患資料。

## 決策

- 假資料階段：**不限制**可使用的模型與送出的內容
- `services/llm/gateway.py` 保留 `preprocess` hook（目前 pass-through），作為未來去識別化的插入點
- log、例外訊息不得含病患識別資料的規定照常適用（與本決策無關）

## 影響

- 好處：開發期可自由比較各家模型效果
- 風險：若誤將真實資料匯入，會直接送往雲端 API
- **後續（必要）**：接真實資料前須新增 ADR 取代本決策，在下列方向擇一或組合：
  - 送出前強制去識別化
  - 僅允許地端模型
  - 僅允許院方核准、具資料保護合約的雲端服務
