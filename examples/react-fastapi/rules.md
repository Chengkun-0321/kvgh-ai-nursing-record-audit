# ③ 業務規則與異常行為

應付金額由後端 `POST /api/discount` 計算，前端表單送出並顯示結果。

| 編號 | 規則 |
|---|---|
| R1 | `amount` 大於或等於 1000 時，先打九折（乘以 0.9）。小於 1000 不打折。 |
| R2 | `is_member` 為 true 時，在 R1 之後再減 50 元。 |
| R3 | 結果不得低於 0；低於 0 時回傳 0。 |
| R4 | 結果四捨五入到小數第 2 位。 |
| R5 | 前端表單有「金額」輸入框（label 為「金額」）、「會員」核取方塊（label 為「會員」）、「計算」按鈕；按下後以輸入值呼叫 `calculate`，並顯示「應付金額：{結果}」。 |
| E1 | `amount` 為負數時回 422。 |
| E2 | `amount` 不是數字（字串、null、布林值）或缺少時回 422。 |
| E3 | `is_member` 不是布林值或缺少時回 422。 |
| E4 | 前端「金額」為空白時，「計算」按鈕為停用狀態（disabled）。 |
